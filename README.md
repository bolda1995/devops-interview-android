# DevOps Interview

Нативное Android-приложение для подготовки к техническому собеседованию. Вопросы и ответы встроены в приложение, подключение к интернету не требуется. Доступны поиск, фильтры по теме и уровню, тренировка в случайном порядке, избранное и отметки изученных вопросов. Можно написать свой ответ: текст сохраняется на устройстве для каждого вопроса. Пример ответа скрыт до нажатия кнопки; оценка остаётся самостоятельной. Кнопки возврата позволяют выйти из тренировки и банка вопросов. Данные прогресса сохраняются на устройстве. Согласно источнику, ответы Q-00001—Q-00080 проработаны подробно, остальные — краткие опорные материалы, не полностью рецензированные решения.

## Сборка

Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle, затем выберите **Build → Build APK(s)**. Понадобятся JDK 17 или новее и Android SDK Platform 37. Минимальная версия устройства — Android 6.0 (API 23).

Источники: `app/src/main/assets/questions.md` и `app/src/main/assets/answers.md`. Для обновления сохраните формат заголовков, строк вопросов и блоков ответов, и пересоберите приложение. Вопросы и ответы сопоставляются по идентификаторам; для сохранения прогресса идентификаторы должны оставаться прежними.

## Сравнение ответа

Кнопка «Сравнить с примером» выделяет совпадающие слова и другие слова из примера с учётом их частоты в базе. Сравнение выполняется на устройстве без интернета. Это простая статистическая обработка текста, а не языковая модель: она не понимает синонимы, отрицания и смысл и не определяет правильность ответа. Опорные ответы после Q-00080 не являются полностью проверенными эталонами.
